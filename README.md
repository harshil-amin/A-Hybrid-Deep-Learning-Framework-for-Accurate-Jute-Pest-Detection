# A-Hybrid-Deep-Learning-Framework-for-Accurate-Jute-Pest-Detection

This repository contains the implementation of a deep learning pipeline to classify pest images in jute plants. It compares multiple CNN architectures (DenseNet201, EfficientV2, InceptionV3) with and without data augmentation and builds hybrid models using Vision Transformers (ViT).

## 📌 Features

- CNN baseline models with and without augmentation.
- Vision Transformer (ViT) integration with CNN backbones.
- Performance comparison across architectures.
- Pest classification use-case relevant to agriculture.

## 🧪 Models Used

- DenseNet201
- EfficientV2
- InceptionV3
- Hybrid Models (CNN + ViT)
